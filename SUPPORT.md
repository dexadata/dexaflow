# Support

Where to get help with Dexaflow.

## Questions and design discussion

Use [GitHub Discussions](https://github.com/dexadata/dexaflow/discussions) for questions, design ideas, and general help. That is the primary community channel for this repository.

## Bugs and feature requests

Open a GitHub issue using the templates under [Issues](https://github.com/dexadata/dexaflow/issues/new/choose). Include reproduction steps, expected behavior, actual behavior, and environment details (OS, Go version, Kubernetes version if applicable).

## Security vulnerabilities

Do not open a public issue for security problems. Follow [`SECURITY.md`](SECURITY.md) and use [GitHub private vulnerability reporting](https://github.com/dexadata/dexaflow/security/advisories/new).

## Contributing

To change the code or docs, read [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`AGENTS.md`](AGENTS.md) before opening a pull request.

## Commercial support

This repository does not offer paid support. Commercial support and the managed service, Dexaflow Cloud, are offered by Dexadata; see [dexadata.ai](https://dexadata.ai). In this repository the maintainers answer community questions and review contributions as capacity allows; there is no SLA for response time beyond the guidance in `CONTRIBUTING.md`.
