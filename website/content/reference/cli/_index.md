Every `dexaflow` command and flag. This reference is **generated from Cobra** on
every build (`website/scripts/gen-cli.sh`), so it never drifts from the binary.
The per-command pages (`dexaflow`, `dexaflow lite`, `dexaflow init`, ...) are listed in
the sidebar.

You can also run `dexaflow --help` (and `dexaflow <command> --help`) for the same
surface at the terminal. The pre-rename `leoflow` command name still works.
