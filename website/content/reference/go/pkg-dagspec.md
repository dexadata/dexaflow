Package dagspec validates a compiled dag.json with the rules the engine applies when the DAG is registered, so a service that registers DAGs through the API can refuse a bad one before it sends it \(\#1877\).

It works on the dag.json bytes, the same document POST /api/v2/dags/\{dag\_id\}/dagVersions takes, and depends on no storage, server or API code. Validate covers what holds on every install: the JSON Schema, the task graph, params, execution metadata, placement, resource quantities and the cron schedule. CheckLimits adds the per\-tenant limits an operator may set \(min\_schedule\_interval\_seconds and max\_task\_pool\_slots\). What depends on the server's own configuration \(the resource unit, deploy.require\_digest, source mode and the execution allowlist\) and max\_dags, which needs the tenant's count, are checked only by the server.

```go
func MinScheduleInterval(schedule string) (gap time.Duration, ok bool)
```

MinScheduleInterval returns the shortest gap a schedule leaves between two runs, the figure min\_schedule\_interval\_seconds is compared with. ok is false when the schedule never fires on a cron \(empty, @once, @continuous, a date that does not exist\) or does not parse.

<a name="Validate"></a>
## func [Validate](<https://github.com/dexadata/dexaflow/blob/main/pkg/dagspec/dagspec.go#L43>)

```go
func Validate(dagJSON []byte) error
```

Validate reports whether dagJSON is a dag.json the engine registers, and every rule it breaks otherwise. A schedule that does not parse as a cron is refused here, as \`dexaflow compile\` refuses it: the server registers such a DAG but never schedules it.

<a name="Limits"></a>
## type [Limits](<https://github.com/dexadata/dexaflow/blob/main/pkg/dagspec/dagspec.go#L31-L37>)

Limits are the tenant limits a dag.json is checked against. A zero field is unlimited, as on a tenant created without limits.

```go
type Limits struct {
    // MinScheduleIntervalSeconds is the shortest gap, in seconds, the DAG's
    // schedule may leave between two runs.
    MinScheduleIntervalSeconds int
    // MaxTaskPoolSlots caps a task's pool_slots.
    MaxTaskPoolSlots int
}
```
