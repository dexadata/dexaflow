# Overrides for the runtime/data lock (runtime/data/README.md). Each line beats
# a dependency's declared bound; keep it only while the reason holds.
#
# dbt-bigquery 1.12.1 caps google-cloud-storage below 3.2, while gcsfs (pulled
# by apache-airflow-providers-google) needs >= 3.11 from 2026.6.0, the first
# release on an fsspec without CVE-2026-104851. dbt-bigquery only builds a
# storage Client and calls bucket/get_bucket for Python models, stable across
# 3.x; the image build imports its client module. Drop this line once a
# dbt-bigquery release lifts the cap.
google-cloud-storage>=3.11

# google-cloud-aiplatform 2.6.0 (pulled by apache-airflow-providers-google) caps
# litellm below 1.97, and every litellm before 1.100.4 carries CVE-2026-114612
# (HIGH, privilege escalation in the litellm proxy). The image never runs the
# proxy; aiplatform imports litellm only for its evaluation extras. The image
# build imports the Google provider. The upper bound keeps 1.103, the newest
# patched line: later releases cap huggingface-hub below 2 and filelock below
# 4, which would trade both down. Drop this line once an aiplatform release
# lifts the cap.
litellm>=1.103.1,<1.104
